# Reto 01 (Módulo 04): Tarjeta de Presentación con React

## 📌 Descripción

Este proyecto consiste en una **Tarjeta de Presentación** desarrollada con **React** y **Vite**. La tarjeta muestra información estática como el nombre, la profesión, un mensaje de presentación, correo, ubicación y habilidades. Es el primer acercamiento a React, practicando componentes funcionales y la sintaxis de JSX.

## 🎯 Objetivos

- Crear un proyecto de React con Vite.
- Definir y usar componentes funcionales en React.
- Entender la sintaxis básica de JSX.
- Renderizar información estática en la interfaz.
- Ejecutar y probar la aplicación en el navegador.

## ✨ Funcionalidades

- **Componente `Tarjeta`:** Muestra la información de presentación.
- **JSX:** Uso de llaves `{}` para incrustar variables.
- **Estilos en línea:** Objetos de JavaScript con propiedades CSS.
- **Renderizado de listas:** Uso de `.map()` para las habilidades.
- **Diseño moderno:** Fondo con degradado, tarjeta con sombra y avatar circular.

## 🧠 Conceptos Practicados

| Concepto | Uso en el reto |
|----------|----------------|
| **React** | Biblioteca para construir interfaces de usuario. |
| **Vite** | Herramienta de desarrollo y empaquetado. |
| **Componentes funcionales** | `Tarjeta.jsx` y `App.jsx`. |
| **JSX** | Sintaxis similar a HTML dentro de JavaScript. |
| **`{}` en JSX** | Incrustar variables y expresiones. |
| **`style` en JSX** | Objetos de JavaScript con propiedades CSS. |
| **`.map()`** | Renderizar listas de elementos. |
| **`key` prop** | Identificador único para elementos en listas. |
| **`import` / `export`** | Módulos de JavaScript. |

## 📂 Archivos

- `index.html`: Estructura base del HTML.
- `src/main.jsx`: Punto de entrada de React.
- `src/App.jsx`: Componente principal.
- `src/Tarjeta.jsx`: Componente de la tarjeta.
- `src/App.css`: Estilos del componente principal.
- `src/index.css`: Estilos globales.
- `package.json`: Dependencias y scripts.
- `README.md`: Este archivo con la documentación.
