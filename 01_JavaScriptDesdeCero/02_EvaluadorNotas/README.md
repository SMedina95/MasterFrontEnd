# Reto 02: Evaluador de Notas con Mensajes Personalizados

## 📌 Descripción

Este proyecto consiste en un programa en JavaScript que evalúa la nota de un estudiante y genera un mensaje personalizado según el rango en el que se encuentre la calificación. Se practican conceptos fundamentales como variables, operadores de comparación y estructuras condicionales (`if / else if / else`).

## 🎯 Objetivo

Aplicar los conceptos básicos de toma de decisiones en JavaScript para clasificar una calificación dentro de diferentes rangos y mostrar un mensaje acorde al resultado obtenido.

## 📋 Reglas de Evaluación

| Rango de Nota | Mensaje |
|---------------|---------|
| 90 o más | **Excelente** |
| Entre 75 y 89 | **Bien** |
| Entre 60 y 74 | **Suficiente** |
| Menor de 60 | **No aprueba** |

## 🧠 Conceptos Practicados

- Declaración de variables con `let` y `const`
- Operadores de comparación: `>`, `<`, `>=`, `<=`
- Operadores lógicos: `&&`
- Estructuras condicionales: `if`, `else if`, `else`
- Uso de funciones para encapsular lógica reutilizable
- Impresión de resultados en consola con `console.log`

## 📂 Archivos

- `evaluador-notas.js`: Contiene la lógica del evaluador y las pruebas con distintos valores.
- `index.html`: Página que muestra los resultados del programa en el navegador (para GitHub Pages).
- `README.md`: Este archivo con la documentación del reto.
