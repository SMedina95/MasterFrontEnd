# Reto 03: Clasificación de Frutas con Arreglos y Ciclos

## 📌 Descripción

Este proyecto consiste en un programa en JavaScript que clasifica un arreglo de frutas según su tipo y cuenta cuántas hay de cada tipo. Se practican conceptos fundamentales como **arreglos (arrays)**, **objetos** y **ciclos (loops)**, tanto `for` como `while`.

## 🎯 Objetivo

Aplicar los conceptos básicos de arreglos y ciclos en JavaScript para recorrer una colección de datos, clasificarlos y generar un conteo por categoría.

## 📋 Instrucciones del Reto

- Declarar un arreglo llamado `frutas` con varios tipos de frutas.
- Crear un objeto para almacenar la cantidad de cada tipo de fruta.
- Usar un ciclo `for` o `while` para recorrer el arreglo y contar las frutas.
- Imprimir en la consola la cantidad de cada tipo de fruta.
- **Opcional:** Implementar la solución con ambos ciclos (`for` y `while`).

## 🧠 Conceptos Practicados

- Declaración de arreglos: `const frutas = [...]`
- Acceso a elementos por índice: `frutas[i]`
- Propiedad `.length` de un arreglo
- Creación de objetos literales: `{}`
- Acceso dinámico a propiedades: `objeto[clave]`
- Ciclo `for` clásico
- Ciclo `while`
- Método `forEach` (bonus)
- Ciclo `for...in` para iterar sobre propiedades de un objeto

## 📂 Archivos

- `clasificacion-frutas.js`: Contiene la lógica del programa con tres soluciones (for, while, forEach).
- `index.html`: Página que muestra los resultados del programa en el navegador.
- `README.md`: Este archivo con la documentación del reto.
