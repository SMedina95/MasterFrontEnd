# Reto 04: Seguimiento de Libros

## 📌 Descripción

Este proyecto consiste en un programa en JavaScript que permite llevar un registro de los libros que has leído. Se practican conceptos fundamentales como **funciones**, **arreglos** y **manipulación de datos**.

## 🎯 Objetivo

Aplicar los conceptos básicos de funciones en JavaScript para crear un sistema sencillo que permita agregar y mostrar libros leídos.

## 📋 Instrucciones del Reto

- Definir una función `agregarLibro(titulo)` que añada un libro a un arreglo llamado `librosLeidos`.
- Definir una función `mostrarLibrosLeidos()` que imprima todos los libros que has leído.

## 🧠 Conceptos Practicados

- Declaración de funciones con `function`
- Parámetros y argumentos
- Arreglos: `const librosLeidos = []`
- Métodos de arreglos: `.push()`, `.splice()`, `.indexOf()`, `.forEach()`
- Condicionales: `if / else`
- Validación de datos (truthy / falsy)
- Uso de `return` para salir de una función

## 📂 Archivos

- `seguimiento-libros.js`: Contiene las funciones del sistema y las pruebas.
- `index.html`: Página que muestra los resultados del programa en el navegador.
- `README.md`: Este archivo con la documentación del reto.
